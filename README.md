# Vibe Coding Implementation: Simple Calculator

This branch contains the simple calculator built using the **Vibe Coding** methodology.

## What is Vibe Coding?
Vibe coding is an unstructured, free-flowing approach to software development. It relies on writing code manually or with basic AI autocomplete off the top of your head, without prior architectural planning, formal specifications, or rigid project structures.

## Workflow Used
1.  **Manual Setup:** Created the project skeleton (`app.py`, `requirements.txt`, `templates/index.html`) directly in the root directory.
2.  **Unassisted Development:** Wrote the Flask routing logic and frontend HTML/CSS/JS without the use of specialized AI planning tools.
3.  **Iterative Testing:** Ran the local server, checked the browser, fixed errors on the fly, and refined the UI.
4.  **Direct Commit:** Staged and pushed the working code directly to the repository.

## Advantages
* **Zero Friction:** You can start writing code the second the repository is cloned.
* **Creative Freedom:** Excellent for visual tasks where you want to tweak CSS and layout by "feel" rather than rigid rules.
* **No Tooling Overhead:** Does not require installing or learning third-party CLI tools or AI agent commands.

## Disadvantages
* **Lack of Structure:** Without a plan, the codebase can quickly become disorganized as new features are added.
* **Context Loss:** If an AI is used later to help debug, it has no reference document to understand the *intended* architecture.
* **Harder to Collaborate:** Teammates have to read the raw code to understand the system, as no design documents exist.
